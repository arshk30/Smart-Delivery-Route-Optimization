# Smart Delivery Route Optimization System Using Python

## Project Description
The Smart Delivery Route Optimization System is a Python-based application developed using Tkinter. It helps find the shortest delivery routes between different locations and optimizes delivery routes to reduce total travel distance.

## Features
- Find the shortest route between two locations.
- Calculate the total delivery distance.
- Optimize routes using the Greedy Nearest Neighbour approach.
- Add new delivery locations.
- Add roads and their distances.
- Display the delivery network graphically.

## Algorithms Used
1. **Dijkstra's Algorithm:** Finds the shortest path between two locations.
2. **Greedy Nearest Neighbour Algorithm:** Selects the nearest unvisited location to create a delivery route.

## Technologies Used
- Python
- Tkinter
- Heapq
- Math

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python delivery_route.py
```
